## Technology Stack
 
This project leverages the following technologies:
 
- **[Tailwind Css, React.Js, Firebase, Hot-toast, Google Auth](https://final-56hzbb792-jaibansal007s-projects.vercel.app/):** React.js used for setting up routing, Tailwind for creating front-end design, Firebase for database and Google authentication, Hot-toast for notification system.
 
## Key Features
 
- **Secure Login:**  Supports multi-factor authentication for secure user access.
 
- **Multiple Spreadsheets:** Manage multiple sheets within a single document for organized data handling.
- **In-Document Chat:**  Built-in chatbox for seamless team communication without leaving the spreadsheet.
- **Cloud-Based:**  Hosted on a scalable cloud infrastructure for high availability and performance.
