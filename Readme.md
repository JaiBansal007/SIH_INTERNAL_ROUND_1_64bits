## Project Overview
 
SocialCalc is a cloud-based spreadsheet platform that simplifies data management and enhances team collaboration. Below is a summary of its key features and objectives:
**Key Features**
 
    Secure Login: Supports multi-factor authentication,google authentication for secure user access.
    In-Document Chat: Built-in chatbox for seamless team communication without leaving the spreadsheet.
    Cloud-Based: Hosted on a scalable cloud infrastructure for high availability and performance.
    Responsive UI/UX
 
**Key Objectives**
 
    Improve Usability: Offer an intuitive interface for users of all skill levels.
    Enhance Collaboration: Facilitate real-time teamwork on spreadsheets.
    Ensure Security: Implement robust security measures to protect user data.
    Implement cloud storage using Firebase for user-specific data
 
## Tech-Stack Used
 
HTML, Tailwind CSS, Material UI, Javascript, React.Js, Firebase, Hot-Toaster, Google Auth
